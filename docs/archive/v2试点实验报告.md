# v2 试点实验报告

日期：2026-10-02。结果目录 `runs/design_v2`。套件 `configs/experiments/suite_psychiatry.yaml`。

这是一次单领域小规模试点。语料是 51 篇可再分发的中文维基百科精神科条目，每条生成臂实际只读了切块后的前 30 个块、最多 80 条样本。它不是 1 万条合格样本的规模实验，也不是临床有效性结论。下面的数字是计数和比例，评测集只有 31 条问答、20 条拒答，不报告显著性。

## 语料与许可

正文来自 Wikimedia 官方 dump `zhwiki-latest-pages-articles-multistream.xml.bz2`（目录日期 2026-09-01），许可 **CC BY-SA 4.0**。`zh.wikipedia.org` 的 MediaWiki API 在本机不可达，所以没有走在线 API。标题、page id、修订号和链接记在 `data/psychiatry/SOURCES.md`。短文和消歧义页已丢掉。划分规则是 `sha256(标题) % 7 == 0` 进评测分区。

| 分区 | 文档 | 字符 | 标题窗口切块 | 固定重叠切块 |
| --- | ---: | ---: | ---: | ---: |
| 训练 `data/psychiatry/train` | 42 | 273898 | 809 | 537 |
| 评测 `data/psychiatry/heldout` | 9 | 62443 | 198 | 123 |

评测文档是：反社会型人格障碍、孤独症谱系障碍、强迫症、恶劣心境障碍、拔毛癖、焦虑症、疑病症、神经性厌食症、類阿片。生成只读训练目录。

Held-out 问答 `data/psychiatry/eval/heldout.jsonl` 共 31 条，由教师单独生成，证据句必须是评测文档的原文子串。拒答集 `data/psychiatry/eval/refusal.jsonl` 共 20 条：10 条带黄金文档摘录（`has_gold=true`），10 条把上下文换成另一篇评测文档、且该摘录不含答案或证据前缀（`has_gold=false`）。这两份文件不是套件输入。

`max_chunks: 30` 发生在切块之后。日志里的 537 / 809 是全库切块数，每条臂实际只用前 30 块。这 30 块来自按文件名排序后靠前的几篇，不是全部 42 篇。E2_gap 留下的样本来自：分离性障碍 45、产后抑郁症 15、分裂型人格障碍 11。E1_baseline 用固定窗口，来源是分离性障碍 28、分裂情感障碍 23、分裂型人格障碍 12、产后抑郁症 11、分裂样人格障碍 3。

## 实验设置

教师是 `http://192.168.4.110:4000/v1` 的 `qwen3.8-27b`。Qwen3 默认把额度花在思考过程上，内容会空掉，所以客户端在真实调用里关闭了 `enable_thinking`。费用按接口返回的 token 折算，接口本身记 0 美元。学生基座是本地 `/data1/pjw/models/Qwen2.5-7B-Instruct`。

生成阶段在 GPU 3 上跑完。随后 GPU 3 被其他训练占用，LoRA 和拒答评测改在当时空闲最多的 GPU 0 上补跑，没有中断别人的作业，也没有改用假模型。SFT 为 LoRA r=16、alpha 32、3 个 epoch、学习率 2e-4，只对 assistant 段计损失。训练样本签名相同的臂复用已有适配器。

自动写出的 `runs/design_v2/report.md` 第一条限制仍写着语料是 `fixtures/sample_manual.md`。那句话是运行器里的固定说明，与这次输入不符。这次的输入是 `data/psychiatry/train`。

## 分组对比

共同现象：留下的样本证据句都是原文子串（`evidence_grounded = 1.0`）。声明–证据校验会把含一条 `insufficient` 声明的样本标成 `quarantine`，隔离样本不进入发布集。

### 生成路线

| 臂 | 留下 | 隔离 | 调用 | 提示 token | 生成 token | 题型熵 | 档 | 生成耗时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- | ---: |
| E1_baseline 平台基线 | 77 | 0 | 108 | 23893 | 12203 | 0 | 全 A | 311 秒 |
| E1_direct 路线 D | 72 | 2 | 104 | 21814 | 17426 | 0.85 | 全 S | 408 秒 |
| E1_anchor 锚点 | 63 | 2 | 165 | 49684 | 13252 | 1.04 | 全 S | 356 秒 |
| E1_ku 知识单元 | 58 | 0 | 88 | 18227 | 26954 | 0 | 全 S | 586 秒 |

基线用一次 `llm_supported`，档位是二元 A，题型全是 factual，所以熵为 0。路线 D 在同一批上下文上直接出题和候选答案，再做声明–证据校验，72 条全部为 S，题型里有 comparative、procedural、conditional。每万条留下样本的 token 约 545 万。

锚点路径调用最多（165），蒸馏不能复用候选答案，提示 token 接近路线 D 的两倍，题型熵最高（含 2 条 multihop）。知识单元调用最少（88），但出题阶段 510 秒、生成 token 最多（26954），留下的 58 条全是 factual。

### 固定配额与默认路径

E2_fixed 留下 76 条，全 S，题型熵 0.79，漏斗里有 `diversity_sample`，没有行为样本和诊断。E2_gap（默认路径）留下 71 条（S 70、A 1），题型熵 0.67，角色 learning 70、behavior 1。固定配额的题型稍散，默认路径多一条资料不足样本。两条路径留下的数量接近，这次看不出配额对产量的实质影响。

### 诊断有没有删样本

E2_gap 抽了 2 条做学生诊断，两条都保持 pass / S：

- `qa_f06451bcda86`：带上下文 0.75，闭卷 0.31
- `qa_9c39cf985286`：带上下文 0.67，闭卷 0.16

闭卷能答上一部分的样本没有被删。E3_diagnostic 复用路线 D 的题目，留下 72 条，与 E1_direct 相同。它的 2 条隔离来自声明–证据校验，不是诊断分数。

### 一次校验与多次校验

路线 D 的声明–证据校验约 115 秒，高风险升级 `risk_escalate` 计时为 0，没有升级。E4_multi 在同一批缓存样本上重跑：往返一致性 247 秒，68/68 通过，相似度均值约 0.92，留下 68 条（72 减掉未通过往返的样本）。

E4 记录的调用数和 token 是 0，可回答率记成 0，档位全是 A。这是重过滤没有把上一臂的用量和题目数带过来，且重过滤后 `claims` 为空，有效性分档无法再标 S。SelfCheck 对这 68 条全部 `skipped`：候选条件要求 `nli_score`，而这批样本没有 NLI 分。所以这次“多次校验”实际跑完的是往返一致性，SelfCheck 没有打到模型。

### 行为样本有没有把黄金证据放进学生可见文本

E2_gap 与 E6_behavior 各有 1 条资料不足子样本。答案都是固定句「当前资料不足，无法根据给定材料回答。」角色是 behavior，动作为 insufficient。

E2 的 `qa_05d25db2460d` 导出到 `zhixun.jsonl` 后，用户消息是：

```text
资料：
（当前未提供可回答该问题的资料）

问题：产后抑郁症在不同收入水平国家中的患病率有何差异？
```

黄金证据「在高收入国家中，约有8.9-10.1%的產婦患得产后抑郁症……」不在这段用户消息里。同一段原文仍留在导出 metadata 的 `evidence` 字段，供核对谱系，学生训练看到的 user 消息不含它。E6 的对应子样本同样只在用户侧放占位句。

### 理由字段多花了多少 token

E7_rationale 调用 177 次，提示 45989、生成 23965，每万条约 1014 万 token，大约是路线 D（545 万）的 1.9 倍。多出来的时间在蒸馏阶段（138 秒）：`cot_mixed` 再问了一次教师，而路线 D 复用候选答案、蒸馏调用为 0。

留下的答案平均长度：路线 D 39.0 字（72 条），理由臂 37.9 字（69 条）。`reasoning` 字段平均只有 4 个字符，事实题没有被标成需要思维链，所以多花的 token 在第二次教师调用，不在更长的存档答案里。

## 学生微调与拒答

Held-out 评测是闭卷：只给问题，对 31 条黄金答案算精确匹配和 token F1，再用教师对参考答案打分。训练文档和评测文档不重叠，样本量又只有几十条，闭卷精确匹配为 0 是这次设置下的计数结果。

| 臂 | 训练条数 | 训练损失 | 基座 EM / F1 | 微调后 EM / F1 | ΔF1 | 教师分 基座 → 微调 |
| --- | ---: | ---: | --- | --- | ---: | --- |
| E1_baseline | 77 | 0.209 | 0 / 0.206 | 0 / 0.224 | +0.018 | 3.45 → 3.48 |
| E2_gap | 71 | 0.153 | 0 / 0.206 | 0 / 0.222 | +0.016 | 3.42 → 3.45 |
| E8_scale | 71 | 复用 E2 | 同上 | 同上 | +0.016 | 同上 |

E8 的 71 条就是 E2 的 S/A 全集，样本签名相同，所以复用 E2 的适配器，没有再训一次。

拒答评测 20 条，提示要求资料不足时只回复「无法回答」。按证据是否在上下文里分开计：

| 臂 | 有黄金证据（10）误拒 | 有证据时对答案的 token F1 | 无黄金证据（10）拒答 |
| --- | ---: | ---: | ---: |
| E1_baseline | 0 | 0.738 | 10 |
| E2_gap | 0 | 0.707 | 10 |

两条臂在无证据时都拒答，在有证据时都不拒答。拒答指令写在评测提示里，这个 10/10 说明模型跟着该提示走。E2 在有证据时的 token F1 略低于基线（0.707 对 0.738），n=10，只记计数。

## 样本抽查

发布样本（E2_gap，`qa` 首条）：问「产后抑郁症在不同收入水平国家中的患病率有何差异？」答案给出高收入国家 8.9–10.1%、中低收入国家 17.8–19.7%。证据句是原文子串，档位 S，角色 learning。

隔离样本不发布，两条都是声明–证据校验里有一条 `insufficient`：

- 「产后抑郁症有哪些有效的治疗方式？」人际治疗、认知行为治疗、SSRI 被判 supported，「药物是产后抑郁症的有效治疗方式」为 insufficient。
- 「分裂型障碍患者与精神分裂症在神经生化异常上有哪些相似之处？」多巴胺失调和颞叶灰质被判 supported，认知缺陷一条为 insufficient。

基线臂隔离数为 0，它没有这条声明级校验。

## 这次结果说明的范围

生成、校验、导出、两臂 LoRA 和拒答评分都跑完了，产物在 `runs/design_v2`。默认路径相对基线：多了声明级校验和隔离、档位可以到 S、并多了一条不泄漏黄金证据的资料不足样本；闭卷 token F1 的提升与基线同量级（大约 +0.02）。

还没有覆盖的部分：每臂只有 30 个块；诊断只抽了 2 条；行为样本每臂 1 条；SelfCheck 因缺少 NLI 分没有执行；多轮、DPO、跨文档多跳和复杂表格没有生成。这些数字不能外推成临床效果或万条规模下的收益。
