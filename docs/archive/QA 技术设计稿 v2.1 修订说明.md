## 2. 设计级验收用例

每条只说明设计覆盖的输入与预期行为，以及规则所在章节。没有运行生成、训练或付费调用。

**T01.** 输入：`k_sequential` 产出的 KnowledgeUnit 仍为 `pending`。预期：不得作为已验证知识出题或被后续任务复用。章节：4.2.2、4.3.2、4.7.5。

**T02.** 输入：`k_joint` 同一次调用返回单元和 QA，单元、QA 或对应关系的独立核验尚未完成。预期：不得 `accepted`、发布或跨任务复用。同次自评不算核验。章节：4.2.2、4.3.1、4.3.2。

**T03.** 输入：两份来源都有本次用途授权，冲突已经确认，业务尚未裁定哪一结论为当前事实。预期：确定性事实通道不发布宣称其中一结论为当前事实的样本；仅当 `conflict_behavior: enabled` 且验证通过时，才可产生 `state_conflict` 或按可见规则作答的样本。默认通道关闭。章节：4.1.1、4.4.1、附录 A。

**T04.** 输入：冲突双方中有一份没有相应使用授权，或真实性未确认，或解析不可靠。预期：整条材料保持治理隔离，不能借 `conflict_behavior` 绕过。章节：4.1.1、4.4.1。

**T05.** 输入：较新版本与旧版本结论不同，但学生可见的策略和上下文里没有足够适用规则。预期：不得默认新版获胜，也不得要求学生作出确定选择。旧版仍可成为标明的历史、对照或干扰材料。章节：4.1.1、4.2.3、4.4.1。

**T06.** 输入：路线 D 与路线 K 各自发现的知识点数量不同。预期：覆盖率都映射到比较前冻结的同一目录、同一统计阶段和同一完整覆盖判据。只发现 40 个显眼事实不能用 40 作自己的分母。章节：4.2.8、8.3 E1。

**T07.** 输入：某片段被标为 `unsupported`、`pending` 或零问题输出。预期：进入覆盖损失审计并记录原因，不能从分母中静默删除后当成完全覆盖。章节：4.2.5、4.2.8、6.1。

**T08.** 输入：教师或审计库知道黄金答案，学生最终可见上下文没有支持该主张的材料。预期：RAG 确定性答案不能凭隐藏证据通过事实支持验证。章节：4.3.2、4.4.2、4.7.1。

**T09.** 输入：最初黄金段落已从学生上下文移除，但最终 ContextBundle 中另一可见片段仍支持答案。预期：不得标成完全 `missing`。无法判断时保持待确认或升级。章节：4.3.2、4.4.1。

**T10.** 输入：`closed_book_domain` 样本没有 `student_context_refs`，但有合法核验来源。预期：不因为缺少学生可见引用而判错。章节：1.2、4.3.2、4.7.1。

**T11.** 输入：验证通过后发生脱敏、裁剪、版本替换、引用重排或答案修复。预期：原通过失效，重做受影响的确定性、语义或行为检查。只改审核备注或成本分录且不改变 `validation_subject_hash` 的绑定内容时，不触发全量模型复检。章节：4.1.5、4.7.2。

**T12.** 输入：多个 worker 同时启动生成。预期：准入事务同时预留本批生成和规定验证、升级、审核、抽检费用。不能把生成预算花完后跳过审核。章节：4.8.3。

**T13.** 输入：请求超时后晚到回调，或同一结算事件重复对账。预期：该笔预留只属于 I 或 U 之一；结算进入 S 后重复事件不再入账；仍可能计费的金额不提前释放。重试使用新的 `attempt_id`。章节：4.8.3。

**T14.** 输入：剩余授权额度放不下生成加必需流程预留。预期：缩小批次或停止新增生成；已产生但未验证的样本保持未发布。不放宽事实门槛，不用 B 级补量。章节：3.4、4.8.3–4.8.4。

**T15.** 输入：两条样本的 `supervised_target_tokens` 都是 100，上下文长度不同。预期：报告可以显示相同监督规模，同时显示不同的 `sequence_tokens` 或 `actual_compute`，不称为等计算预算。章节：4.5.4、8.1。

**T16.** 输入：一条样本被重复回放，另一条被 loader 跳过或截断无效。预期：`actually_trained` 和角色 token 按实际暴露更新。跳过或无效截断不按计划值计入。章节：4.5.4、4.6.4、4.7.2。

**T17.** 输入：`accepted` 的主意图比例落在目标区间，`released` 的比例没有。预期：分别报告两种分布和发布缺口，不把合格池达标写成发布达标。章节：4.2.5、4.6.4、6.4。

**T18.** 输入：共同合格池里自然包含学生已经熟悉的知识，G0 不额外加入专门回放。预期：报告这些自然包含的已知样本，不把 G0 描述成纯新知识组。章节：8.3.1。

**T19.** 输入：分别缺少总预算授权、`calibrated_thresholds` 仍为空、`student_probe.enabled=false`。预期：三种情况分别阻止付费批次、阻止把试点候选自动生产发布、允许不配置检查点且选样不读诊断标签。三种缺失不互相替代。章节：1.3.1、附录 A。

**T20.** 输入：数据质量与 `train` 授权已满足，没有训练反馈。预期：可以作出数据可发布的判断；训练收益和模型部署标为未验证或未批准，不用数据质量指标代替。章节：1.3、6.4、7.2、8.3.1。

**T21.** 输入：worker 具备 `read`，授权记录没有 `train`。预期：样本不得进入训练发布或训练消费。章节：4.1.1、4.7.2。

**T22.** 输入：来源的 `allowed_serve_scope` 窄于计划部署范围；随后该来源被撤回。预期：部署不自动获批。撤回后禁用后续使用并失效缓存；已训练模型进入治理评估。删除训练文件不被写成已经消除参数记忆。章节：4.1.1、4.7.5、6.4。

**T23.** 输入：生成、配额、诊断或路由读取 `locked_test` 或 `retention_test`。预期：按分区和用途拒绝。无诊断组不读诊断标签。章节：3.1、4.2.8、4.5.4、8.3.1。

**T24.** 输入：发布数量为零、覆盖权重和为零、预算或比例字段为 `null`。预期：报告不可计算或待配置。不写成 0% 错误、100% 达标或无限额度。章节：4.2.5、4.2.8、4.8.1、4.8.3、附录 A。

## 3. 关键全局一致性

下列标识在流程图、正文规则、实验组和附录 A 中使用同一含义：

- 样本路线只有 `direct_grounded`、`anchor_assisted`、`k_sequential`、`k_joint`。`anchor_assisted` 仍读原文。混合路由是批次比较层，不替代样本路线。
- `evidence_state` 为 `sufficient`、`partial`、`missing`、`conflict`、`ambiguous`。说明冲突的 `expected_action` 为 `state_conflict`，证据不足为 `state_insufficient`。导出示例使用同一英文枚举。
- `unresolved_conflict` 是对象：`deterministic_fact: quarantine` 与 `conflict_behavior: disabled` 同时成立。
- 金融桶 S/I/U/F/H 对应 `spent_settled`、`reserved_inflight`、`unbilled_reserve`、`required_process_reserve`、`safety_margin`，并与 worker 任务状态、`data_stage` 分开。
- 角色混合和回放比例的默认口径都是 `supervised_target_tokens`，比例值保持 `null`。
- 附录示例为 `execution_mode: draft`、`recipe_version: qa-data-v2.1-draft`。`student_probe.enabled: false`，因此检查点可以为空。
- 一期仍不发布跨文档多跳、复杂表格、多轮和 DPO。S/A 共享有效性门槛，B 与 quarantine 不进入正向训练。相似度、检索相关性和多次回答一致不证明事实正确。无上下文答对不删除样本。

`safety_margin` 是账本中的金额桶，`safety_margin_rule` 是授权方给出的余量规则。前者由后者计算，未给出规则时生产付费批次不能启动。
