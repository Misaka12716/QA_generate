# drug_v21 实验报告

微调前后的阅读对象是 `answers.md`。下面的分数只给 16 道锁定测试题做索引。题量小，精确匹配都是 0，token F1 的升降不能当成稳定提升，也不构成上线通过。没有业务给定的 `retention_max_drop`。数据能导出，只说明样本过了发布门，不说明模型变好。

## 锁定测试上的前后对比

学生基座是本地 Qwen2.5-7B-Instruct。对照是默认管线 E2_gap 的 LoRA，以及同一批直接路线问题上选出的 G0–G3。每题都把锁定测试文档里的可见资料放进提示。基座五次评测的分数相同，因为问题和资料没有变。

| E2_gap 默认管线 | 147 | 3121 | 0.0 → 0.0 | 0 / 16 | 0.1688 | 0.2079 | +0.0391 |

| E3_g3 | 111 | 2808 | 0.0 → 0.0 | 0 / 16 | 0.1688 | 0.2744 | +0.1056 |

精确匹配一列是微调前到微调后。答对条数按整句精确匹配计，16 题里前后都是 0。G3 的 token F1 升得最多，G2 的差值小于 0.02。16 题的差值不稳定，结论是看不出稳定提升。

有资料时应作答。基座在 16 题里拒答 3 题，微调后 E2、G1、G2、G3 为 0 题，G0 为 1 题。这是该答却拒答的变化。

资料换成不含答案的干扰段时，正确行为是说明不足。基座 16 题里有 2 题说明不足，微调后五组都是 0 题，其余题仍在作答。干扰条件下没有出现“说明不足变正确”的收益。过度拒答没有单独的业务阈值，这里只把“有资料却拒答”和“无对应资料仍作答”分开计数，不合并成一个通过率。

`answers.md` 收录了 E2_gap 全部 16 题的问题、学生看见的资料、微调前全文、微调后全文、参考答案和变化说明，以及干扰条件下的全文。文首按变好、变差、实质相同、从拒答变成作答分组。E3 各组各保留变化最明显的 4 题全文。
