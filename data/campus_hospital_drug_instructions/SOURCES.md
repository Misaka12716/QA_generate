# 校医院药品说明书语料

校内校医院收集的中文药品说明书文本，用作试验微调与 QA 生成管线的语料来源（与 `data/psychiatry` 同级领域目录）。

## 归档与目录

| 路径 | 说明 |
| --- | --- |
| `校医院收集药品说明书.zip` | 原始压缩包（约 114 MB） |
| `raw/*.txt` | 解压后的说明书正文，每条一个文件 |

单条文件通常以 `URL: http://172.30.0.232:880/Search/ShowInstruction/<id>` 开头，随后为药品名称、成份、适应症/功能主治、用法用量等栏目。

解压后共 **2552** 个 `.txt`，合计约 **1.41 亿** 字符（中位约 1.7k 字符/条）。少数条目实为 **PDF 二进制**（文件名如 `560.txt` 等，以 `%PDF-` 开头），入库或切块前建议过滤或单独 OCR/解析。

## 使用方式

生成管线 `load_documents` 支持 `.txt`，套件 YAML 可将 `input` 指向本目录，例如：

```yaml
input: data/campus_hospital_drug_instructions/raw
```

尚未划分 `train` / `heldout` 与评测问答集；需要时可再按文档 id 或哈希做 holdout，并在此目录下增加 `train/`、`heldout/`、`eval/`。

## 许可与合规

说明书内容可能受药品注册与平台使用条款约束；仅用于校内研究与试验微调时，请遵守数据来源方规定，勿对外公开原始全文。
